# 履带小车开发日志

参赛队伍：明月战队

本车为两台参赛小车中的第一台，以履带底盘为基础平台，承担复杂地形通过与高处方块取放任务。整车由 STM32 主控，PS2 手柄遥控，车体上搭载两个举升高度不同的升降台，分别承载水平转动杆与涵道风扇。

---

## 履带底盘运动

### 功能描述

实现小车在比赛场地内的前进、后退与转向，能够通过高台、坡道、台阶等起伏地形，为车上机构提供稳定的移动平台。

### 设计思路与选型

底盘形式直接决定了整车的通过性上限。备选方案有三类：

| 方案    | 优势                     | 劣势                |
| ----- | ---------------------- | ----------------- |
| 四轮差速  | 结构简单、平地速度快             | 台阶与坡道边缘易架空，越障能力弱  |
| 麦克纳姆轮 | 全向移动、平层机动性最好           | 辊子对地面平整度敏感，越障能力最差 |
| 履带    | 接地面积大、接地比压低，跨越台阶与爬坡能力强 | 转向阻力大、平地速度偏低      |

比赛场地存在高台、坡道与台阶，轮式底盘在这些工况下容易打滑或架空，而履带的接地长度可以跨过台阶棱边，把载荷分散到更大面积上。因此本车选择履带底盘，把"通过性"作为第一优先级，速度让位于可靠性。

### 实现过程

STM32 输出两路 PWM 到电机驱动模块，分别控制左右两侧履带电机。直行时两侧占空比相同，转向时通过左右两侧的速度差实现差速转向，差速的大小对应转向半径的大小。

### 难点与解决

**直行跑偏。** 两侧履带的张紧度、摩擦阻力和电机个体差异不可能完全一致，同一占空比下左右实际转速不同，小车会持续向一侧偏移。解决方式是实测标定：在固定场地让小车直线行驶一段距离，记录偏移方向与偏移量，再对两侧占空比做补偿系数修正，把机械差异在软件层面抵消。

**低速爬坡扭矩不足。** 爬坡时负载显著增大，占空比过低会堵转，过高又会在坡道上冲出去。最终采用分段调速策略，在检测到爬坡工况时提高基础占空比，并把加速过程放缓，避免履带打滑。

### 迭代优化

初版底盘在爬坡时车体后仰明显，重心偏后导致前部履带附着力下降。调整电池与主控的安装位置、把重量前移之后，爬坡姿态明显改善，履带也不易在坡道上打滑。

## 双升降台机构

### 功能描述

在车体上设置两个举升高度不同的升降台，由 2 个独立马达驱动升降，把车上的两套执行机构分别送到不同的作业高度。

### 设计思路与选型

本车的作业对象分布在两个高度层：近地层的方块与高处的方块。如果只做一台升降台，两个执行机构就必须装在同一平台上，会带来两个问题：一是同一时间只能兼顾一个高度，取完低处还要重新举升；二是水平转动杆与涵道风扇在同一高度会互相干扰，杆件旋转时会与风扇发生空间干涉。

因此把执行机构拆分到两个平台上，并让两个平台的举升高度不同，使两套机构各自工作在合适的高度区间，互不争抢行程与空间。

升降驱动采用 2 个独立马达而非单马达联动。独立驱动的价值在于两路可以单独动作：取高处方块时只举升风扇所在平台，另一平台保持不动，减少不必要的动作时间和功率消耗。

### 实现过程

两个升降台并联布置在车体上，各自由一路马达经驱动模块带动升降。两路控制信号独立，由 STM32 分别输出，可以单独启停，也可以同时动作。升降到位依靠行程限位判断，避免马达堵转。

### 难点与解决

**举升到高位时整车重心上移。** 平台升高后，车体对地面的压力分布发生变化，急停或转向时侧倾风险增加。解决方式是在结构上降低非举升部分的安装高度，把电池等重物尽量贴近底盘，让整车重心保持在较低位置。

**两路升降的同步性。** 两个平台同时动作时，由于马达转速差异会出现高低不平。处理办法是让两路各自独立到位判定，不依赖"同时启动即同时到达"的假设，避免相互等待。

### 迭代优化

初版升降台的导向依靠单边支撑，举升到高位时平台有轻微晃动。改进后增加导向约束、把支撑点分布到平台两侧，高位稳定性明显提升。同时把升降行程按实际作业高度重新标定，减少无效行程。

## 水平转动杆的舵机控制

### 功能描述

舵机带动一根水平杆绕竖直轴转动，调整杆端的方位，使执行机构能够对准目标方块。

### 设计思路与选型

水平杆的转动由舵机直接驱动。由于杆件本身有长度，末端执行机构又带来附加重量，舵机输出轴承受的是持续力矩而不是瞬时冲击，选型时扭矩是首要指标。

对比过的两类舵机：小型舵机扭矩约 1.8 kg·cm，塑料齿轮，体积小、重量轻、价格低，适合轻负载小角度动作；大扭矩舵机扭矩约 11 kg·cm，金属齿轮，负载能力强。本车杆件较长、末端有负载，小型舵机的塑料齿轮在带载转动时容易扫齿，定位也会因外力偏移，因此选用大扭矩、金属齿轮的舵机。

### 实现过程

STM32 输出 PWM 信号控制舵机转角，把目标方位角映射为对应的脉宽。舵机转动时先把杆件抬离接触面再旋转，避免杆端与车体或方块摩擦造成堵转。

### 难点与解决

**舵机抖动、角度保持不住。** 初期舵机与主控共用一路电源，舵机启动瞬间电流骤增把电压拉低，表现为舵机来回抖动、主控偶发复位。这个问题在后续的供电设计中单独解决，舵机改用独立降压供电。

**旋转范围的限制。** 水平杆全周旋转会与其他机构发生碰撞，因此在控制上做了角度限位，把转动范围约束在有效作业区间内，同时也减少了不必要的动作时间。

### 迭代优化

初版舵机直接固定在薄板上，带载转动时支架有轻微弹性变形，导致实际角度与指令角度存在偏差。改进后增加支架厚度与固定点数量，把舵机受力传导到车体主结构上，角度重复性明显改善。

## 涵道风扇取高处方块

### 功能描述

在升降台末端安装涵道风扇，利用风扇产生的强推力把位于高处的方块取下并带回。

### 设计思路与选型

高处方块是本车最难处理的作业对象。常规做法是用多自由度机械臂去够，但机械臂的自由度越多，重量、成本和调试量上升得越快，而且在高处伸展时会带来很大的倾覆力矩，对底盘稳定性要求极高。

本车改用"推力"替代"抓取"：让涵道风扇产生定向强气流，直接作用在高处方块上，把方块推落。这样做的收益是结构极简——不需要关节、不需要多级传动，只有一个风扇加一个安装位；动作链路也短，只要升降台到位、风扇对准，就能完成作业。

风扇选用涵道式而非裸桨：涵道外壳对气流起整流和约束作用，把气流集中在一个方向上，同等功率下有效推力更大，同时外壳把桨叶包住，避免与车体结构、方块发生碰撞。

### 实现过程

风扇工作在 7.4 V、直径 30 mm，固定在升降台末端，随平台一起升降到高处作业位置。启动与停止由 STM32 控制，与升降动作联动：平台到位后才启动风扇，避免在举升过程中把风打到无关位置。

### 难点与解决

**反作用力影响车体稳定。** 风扇产生推力的同时会给车体一个反方向的力，风扇功率越大，车体受到的扰动越明显，可能造成位置偏移甚至后仰。解决方式是在启动时采用渐进的占空比上升，避免瞬时全功率带来的冲击，同时依靠履带底盘较大的接地面积吸收反力。

**方块被吹飞而不是取下。** 初期风扇角度过于水平，气流把方块推离作业区而不是拿下来。通过调整风扇俯仰角与作业距离，让气流作用方向与方块的取离路径一致，方块能够落到预定位置。

### 迭代优化

初版风扇直接绑在平台末端，工作时振动明显，长时间运行后固定点有松动。改进后增加减振垫与加固支架，把风扇的振动与平台结构隔离，作业稳定性提升。

## 舵机独立供电设计

### 功能描述

为水平转动杆舵机设计独立供电回路，由 LM2596 降压模块单独供电，使舵机动作不影响主控与其他用电部件的正常工作。

### 设计思路与选型

舵机属于典型的脉冲负载：静止时电流很小，启动与堵转瞬间电流骤增。本车最初把舵机与 STM32 主控接在同一路电源上，出现了两个连锁现象——舵机动作时电压被拉低，主控供电不足导致复位；主控复位后 PWM 信号中断，舵机失去指令又开始抖动，形成恶性循环。

解决思路是把"大电流脉冲负载"和"敏感逻辑负载"从物理上分开。对比过三种做法：

| 方案           | 效果                     |
| ------------ | ---------------------- |
| 共电源 + 加大电容   | 电容只能短时补能，舵机持续动作时压降依然存在 |
| 共电源 + 提高电池电压 | 逻辑电路耐压受限，且不解决瞬时跌落      |
| 独立降压供电       | 舵机与主控各自独立取电，互不干扰       |

最终选择独立降压：电池经 LM2596 降压到舵机工作电压后单独供给舵机，主控走自己的供电回路。两路电源在电气上分开，舵机的电流冲击被限制在自己的支路里，主控电压保持稳定。同时在舵机侧保留滤波电容，进一步抑制瞬态波动。

### 实现过程

LM2596 降压模块输入端接电池，输出端接舵机电源，输出电压按舵机额定电压整定。主控与驱动模块由另一路供电。两路共用同一块电池，但走不同的稳压路径。

### 难点与解决

**降压模块输出能力与舵机峰值电流的匹配。** 舵机堵转时的电流远高于额定值，若降压模块输出余量不足，输出电压会被拉低，表现为舵机无力、角度不到位。通过按峰值电流留出余量选择模块、并在输出端并联电容，解决了动作瞬间的压降问题。

### 迭代优化

初版只在舵机端加电容，抖动减轻但没有根除。改为独立降压后再配合电容，舵机动作时主控不再复位，角度保持稳定，这一改动同时也是整车可靠性的关键一步。

## PS2 手柄遥控与主控

### 功能描述

通过 PS2 手柄对整车进行人工遥控，包括底盘行驶、两个升降台的升降、水平转动杆的转角以及涵道风扇的启停。

### 设计思路与选型

主控选择 STM32。本车需要同时驱动两路底盘电机、两路升降马达和一路舵机，共五路 PWM 输出，且要实时解析手柄信号。STM32 的定时器资源充足，可以独立输出多路 PWM 而不互相干扰；主频与中断响应能力也足以保证手柄数据读取的实时性。相比之下，资源较少的开发板在多路 PWM 与实时通讯同时运行时容易出现时序抖动。

### 实现过程

PS2 接收器与 STM32 通讯，STM32 解析按键与摇杆数据后做统一映射：摇杆控制底盘速度与转向，按键控制升降台与风扇，另一组按键控制水平转动杆的角度。所有执行机构的指令在同一个控制循环内分发，保证动作响应的先后关系可控。

### 难点与解决

**手柄响应延迟、动作卡顿。** 初期手柄数据读取频率偏低，摇杆的连续变化被抽样成台阶式跳变，操作手感明显滞后。解决办法是提高手柄读取频率、缩短主循环周期，并把与手柄通讯相关的中断优先级提上来，避免被其他任务阻塞。

**摇杆死区与误触发。** 摇杆回中后存在零点漂移，会导致小车静止时缓慢爬行。通过在软件中设置死区、把中位附近的小幅输入判定为零，消除了静止漂移。

### 迭代优化

初版把各执行机构的控制逻辑平铺在主循环里，加入的功能越多，循环周期越长。重构后把底盘、升降、舵机、风扇拆成独立的功能模块，各自按自己的节奏更新，主循环只做调度，响应速度与后续扩展性都得到改善。

## 结构抗跌落设计

### 功能描述

整车在 180 mm 高度、底面朝下的自由跌落条件下不发生零件脱落，保证运输与意外碰撞后的结构完整性。

### 设计思路与选型

结构件采用 PLA 打印。PLA 刚性较好、打印精度稳定，适合做承力支架，但脆性偏大，冲击下容易在层间开裂。因此在设计阶段就按"冲击载荷"而不是"静载"考虑：所有受力连接处增加加固筋，把点受力分散为面受力；关键部位预留螺丝锁固点，避免仅靠打印件自身强度承力。

### 实现过程

机架加固、螺丝锁固、零件限位三条措施同时实施：机架在立柱与底板交接处加三角加固筋；模块用螺丝固定在机架上而不是卡扣；对易位移的零件做限位挡边，限制其自由度。

### 难点与解决

**首次跌落测试出现零件松动。** 跌落后发现部分固定点位移，原因是螺丝与打印件之间缺少弹性补偿，冲击能量直接传递到螺纹孔，导致孔位松动。改进办法是在螺丝与打印件之间增加紧固垫片，分散压应力，并重新整定锁固力矩，避免过紧导致打印件开裂。

### 迭代优化

改进后复测，180 mm 跌落后结构完好、无零件脱落。后续又对重量较集中的位置增加支撑，把冲击载荷更多地导向底盘结构。

## 开源引用说明
